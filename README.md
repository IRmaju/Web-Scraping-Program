# 🔍 GitHub Profile Image Finder

A simple and user-friendly **Streamlit** web app that allows users to enter a **GitHub username** and fetch the profile image associated with the account. This app uses **Web Scraping** to extract the profile image URL directly from GitHub.

---

## 🚀 Features:
- **GitHub Profile Image Fetcher**: Enter any GitHub username to fetch the profile image.
- **Real-time Image Display**: The app displays the profile image immediately after fetching it.
- **Error Handling**: If the image is not found or there's an issue, an error message is shown.

---

## 📦 Requirements:

Before running the app, you need to install the necessary libraries. Use `pip` to install them:

```bash
pip install streamlit requests beautifulsoup4


🎨 How It Works:
Enter a GitHub Username: Type the username of any GitHub user into the input box.

Click 'Submit': The app will fetch the profile image and display it below the username input.

View the Profile Image: The image will appear with its direct URL.
